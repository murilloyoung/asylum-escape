# asylum-escape
um jogo de terror 2D inspirado em Slendrina 2D, Fuja do asilo para escapar da freira que te mantém lá

# Artes / Audios 
as artes desse jogo foram utilizadas do itch.io, os sons foram utilizados do youtube ou pixabay. nada da parte gráfica do jogo foi feita com IA, pois valorizo que deve ser feita por humanos

# por que foi criado?
esse jogo foi criado para uma apresentação de trabalho da escola
